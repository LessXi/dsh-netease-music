## 功能

- **左侧栏入口**：点一下就在主面板打开完整音乐界面，不是网页 iframe
- **界面**：正在播放页跟随当前歌曲的沉浸式封面背景、歌单/歌手/专辑详情页头部封面晕染、毛玻璃播放条、卡片悬停浮起并出现播放按钮（点了直接播放，不进详情页）、页面切换淡入、加载时显示骨架占位；进度条悬停显示预览时间、正在播放页封面轻微浮动、空状态配图标、侧边栏选中项带红色指示条；强调色采用网易云红；暗色与浅色主题分别调校（暗色走毛玻璃，浅色加重边界、阴影和歌词对比度）
- **发现**：热门榜单 + 推荐歌单
- **每日推荐**：登录后每天更新的 30 首推荐
- **私人FM**：登录后按口味随机推荐，可换一批；不喜欢的歌点一下「不喜欢」就跳过
- **排行榜**：全部 65 个官方榜单，点进去看曲目
- **歌单详情**：封面、简介（可展开）、标签、创建者头像、播放/收藏/评论数与更新时间，可一键收藏；曲目与评论两个标签，评论支持加载更多
- **搜索**：单曲、歌手、专辑、歌单四类结果，单曲结果可一键播放全部，其余可直接进歌手页或专辑页；结果分页加载，滚动到底自动加载更多（也可点按钮手动加载）；搜索页空态显示搜索历史与热门搜索，点一下直接搜
- **输入联想**：顶部搜索框边打字边出候选（单曲 / 歌手 / 专辑 / 歌单分组），方向键上下选、回车直接放或进详情，点「查看全部结果」进完整搜索页
- **曲目搜索与排序**：歌单、歌手、专辑、我喜欢的音乐四个详情页的曲目列表都支持按歌名/歌手/专辑搜索，按歌名/歌手/时长排序，并显示匹配数；歌单还支持按歌手分组浏览；工具栏滚动时吸顶，鼠标移到曲目行上时序号会变成播放按钮，点一下直接播
- **随机播放**：歌单、歌手、专辑、我喜欢的音乐都有「随机播放」按钮，打乱后从头开始播
- **歌手页**：头像、简介、单曲/专辑数；「热门歌曲」50 首、「全部歌曲」分页加载（可继续加载更多）、「专辑」三栏，专辑卡片可点进专辑详情
- **关注歌手**：歌手页可一键关注/取消关注，未登录时点一下直接弹登录框
- **专辑页**：封面、发行日期、完整曲目列表
- **收藏专辑**：专辑页可收藏/取消收藏，未登录时点一下直接弹登录框
- **我的音乐**：登录后显示个人资料、每日推荐、我的歌单
- **我喜欢的音乐**：登录后同步账号收藏的歌曲，可一键播放全部、随机播放，也能搜索和排序
- **红心收藏**：列表行和播放条都有红心按钮，点一下加入/取消「我喜欢的音乐」
- **最近播放**：本地记录播放过的歌曲（最多 100 首），一键清空
- **播放器**：播放/暂停、上一首/下一首、进度、音量（鼠标滚轮可调）、循环模式（列表循环 / 单曲循环 / 随机，图标可区分）；切到别的面板也继续播放
- **迷你播放器**：离开网易云面板去干别的时，右下角会浮出一个小播放器，显示封面、歌名、进度，可直接切歌或暂停，点一下回到完整界面
- **音质切换**：播放条右侧可在「标准 / 较高 / 极高 / 无损」之间循环切换，会员账号可直接听无损 FLAC；切换时保持播放进度，选择会记住
- **正在播放**：点播放条左侧封面或「歌词」按钮进入详情页，左侧大封面、播放控制与进度条、收藏与「接下来播放」预告（列出后面 3 首，点哪首直接跳播那首），右侧滚动歌词（点歌词跳转，可开关翻译、切换字号，或进入全屏歌词）或播放队列；歌手名和专辑名可点，直接跳到对应页面
- **播放队列管理**：正在播放页的队列可移除单曲、一键清空、按歌名/歌手/专辑搜索过滤；移除正在播的那首会自动接着播下一首
- **右键菜单**：在任意曲目行上右键（或按菜单键），可「立即播放」「下一首播放」「加入播放队列」「查看歌手」「查看专辑」「复制歌曲链接」「歌曲信息」（弹窗显示专辑、时长、音质、码率、文件大小与格式），登录后还能「收藏到歌单」
- **歌曲评论**：正在播放页第三个标签，显示热门评论与最新评论，可继续加载更多
- **系统媒体控制**：支持 Windows 媒体键与任务栏媒体浮层，空格键快速播放/暂停
- **键盘快捷键**：空格播放/暂停，`←` / `→` 后退/前进 5 秒，`Ctrl`+`←` / `→` 上一首/下一首，`↑` / `↓` 调音量，`M` 静音；在输入框里打字时不会误触发
- **会话恢复**：刷新页面或重新打开面板后，播放队列、音量、循环模式与播放进度都会恢复，点播放从上次的位置继续
- **列表缓存**：歌单、歌手、专辑、榜单、搜索等页面数据会在本次会话内保留，来回切换时立即显示，不再重新转圈
- **三种登录方式**：自动登录（推荐）、扫码登录、粘贴 Cookie

## 安装

### 方式一：插件管理界面（推荐）

1. 克隆本仓库到本地任意目录：

   ```bash
   git clone https://github.com/LessXi/dsh-netease-music.git
   ```

2. 打开 DSH 的插件管理，选择安装本地 bundle，目录指向刚克隆的 `dsh-netease-music`
3. 重启客户端，左侧栏出现云朵图标

### 方式二：手动加入 profile

在 profile 的 `package.json` 里：

```jsonc
{
  "dependencies": {
    "@local/dsh-netease-music": "link:/绝对路径/dsh-netease-music"
  },
  "dsh": {
    "profile": {
      "bundles": [
        // ……原有 bundle，保持顺序
        "@local/dsh-netease-music"
      ]
    }
  }
}
```

然后重新安装依赖并重启客户端。包名带 `@local/` 前缀是刻意的本地作用域，安装时保持原样。

## 使用

打开左侧栏的网易云音乐图标后：

- 左侧导航「发现 / 排行榜 / 我的音乐」
- 顶部搜索框输入歌名回车，结果上可切换「单曲 / 歌手 / 专辑 / 歌单」，点歌手或专辑进详情页
- 双击曲目行或点播放按钮开始播放；在曲目行上右键可「立即播放 / 下一首播放 / 加入播放队列」，登录后还可「收藏到歌单」
- 底部是播放条，切到其他面板后仍可继续播放
- 点播放条左侧封面或右侧「歌词」按钮打开正在播放页，可看滚动歌词（点歌词跳转，右上角可开关翻译、切换字号，或点全屏按钮进入整屏歌词，按 `Esc` 退出）或播放队列

## 登录

弹窗默认是**自动登录**，点「打开登录窗口」后会启动一个独立的浏览器窗口（不碰你平时用的浏览器），在里面扫码或账号密码登录，插件会自动读取登录状态、关闭窗口。

另外两个标签是兜底：

- **扫码登录**：直接显示二维码。网易云风控较严时手机确认后可能返回 `8821`，此时请改用自动登录或粘贴 Cookie
- **粘贴 Cookie**：从浏览器 `music.163.com` 的请求头里复制 `Cookie`，粘贴进输入框

登录后可以播放需要权限的歌曲（能否播放取决于账号本身的会员状态）。

## 实现说明

- **Host 端**（`index.js`）：注册 `/api/netease-music/*` 路由，代理网易云接口（weapi 加密链路 + 免加密老接口），校验请求 Origin 只允许同源
- **Client 端**（`client.js`）：`sidebar.panellist` + `main` 两个 slot，纯 React 组件渲染，样式只用 DSH 主题变量
- **二维码**（`qr.js`）：自带纯 JS 二维码编码器，无第三方依赖
- **自动登录**（`login-assistant.js`）：用本机 Chrome/Edge 的独立 profile 目录启动浏览器，通过 CDP 读取登录 Cookie 后关闭窗口
- **登录过期提示**：登录凭证失效时面板顶部会出现一条提示，点右侧「重新登录」直接打开登录框，不用再猜为什么点了没反应
- **播放器**：单例放在 `shell.overlay` 的隐藏 `<audio>` 上，切面板不中断；同时上报 `navigator.mediaSession`，支持系统媒体键

所有代码是纯 JavaScript，没有构建步骤。

## 隐私与安全

- 不上传、不收集任何数据
- 登录 Cookie 只保存在本地 `<profile>/netease-music-cookies.json`，只保留登录必需字段
- 只向 `music.163.com` 及其 CDN 发请求，不经过任何第三方服务
- 所有 API 路由校验 `Origin`，拒绝跨站调用

## 已知限制

- VIP/会员歌曲需要登录，且能否播放取决于账号会员状态
- 自动登录需要本机装有 Chrome 或 Edge
- 网易云接口没有公开文档，升级后可能需要适配
